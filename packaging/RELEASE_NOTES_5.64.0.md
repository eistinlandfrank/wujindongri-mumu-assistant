# v5.64.0 · 多手机窗口与界面整理

下载 `WJDRMuMuAssistant_v5.64.0_Portable.exe` 后双击使用，无需安装 Python 或安装向导。首次启动会校验并解压运行环境；需要 Windows10/11、MuMu 和已开启 ADB 的游戏实例。

- 全部8页完成布局检查，顶部标题与设备栏分离；小窗口可滚动，设置窗口保持浅色，修复关于页白底白字。
- 新增“多手机窗口”：逐台打开，或一次打开其他在线设备。默认不启动任务，每台手机独立设置、开始和停止，F8统一急停。
- 标题栏显示绑定设备，日志过滤到本机，丢弃旧手机迟到截图，运行中不替换ADB连接；同一父窗口不会重复打开同一手机子窗口。
- 配置、体力账本的读改写增加跨进程保护，避免并发覆盖其他账号记录。
- 保留5.63的巨兽所有权、命名“打野”、连续循环及同目标冲突取消/重新搜索修复。

验证：82项关键回归＋8项UI/跨进程测试通过；两台1440×2560真实MuMu独立连接、读取新帧和8页导航通过。便携包从非源码目录首次启动10.47秒，第二窗口6.36秒；三个核心模块冻结字节码及全部资源与当前源码一致。
